## 项目名称

**moonbase —— 零依赖、跨后端的 MoonBit 底层基础设施库**

## 赛道

新项目赛道（开源库 / 生态包）

## 一句话

纯 MoonBit、零 FFI、零第三方依赖的块分配器与定容容器库，native / js / wasm-gc 三后端全测，为嵌入式、游戏、运行时等「GC 不友好」场景打地基。

## 解决的生态缺口

1. **生态质量痛点**：mooncakes 包数量增长快，但语言演进快，半年不更新的库普遍编译不过。本库零依赖、纯 MoonBit，天然免疫语言迭代。
2. **底层库薄弱**：活跃维护集中在编译器周边，跨后端、通用的底层基础设施（分配器、定容容器）缺失。
3. **无 GC 场景空白**：嵌入式/实时/热路径场景需要确定性内存管理，现有生态以 GC 容器为主。

## 技术方案

- 内存来自 `Bytes`/`FixedArray` 缓冲区，分配器返回字节偏移句柄，分配过程零 GC 分配
- `Allocator` trait 统一接口；bump/slab/buddy 三种分配器；`Arena[T]` 类型化分配
- 契约化 API：`Option` = 资源耗尽，`abort` = 契约违反；全部公开 API 标注复杂度
- 质量：`moon check` 零警告、每模块确定性伪随机属性测试（不变量校验）、三后端测试矩阵、CI 零 FFI 门禁
