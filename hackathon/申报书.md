## 项目名称

moonbase —— 零依赖、跨后端的 MoonBit 底层基础设施库（块分配器与定容容器）

## 项目简介

moonbitlang/core 已提供成熟的动态 GC 容器（Queue/Deque/HashMap 等），但「GC 不友好」场景（嵌入式、游戏热路径、编译器运行时）需要 core 不提供的保证：容量固定、分配时机可控、回收时点确定。moonbase 与 core **互补而非重叠**——定容、分配路径零堆分配的块分配器与容器，内存来自调用者提供的固定缓冲区，容量用尽即显式拒绝，从不静默扩容；两侧取舍由同负载对照基准量化（[docs/benchmarks.md](../docs/benchmarks.md)）。

库本体（mem/collections）不 import 任何包——连 core 都不依赖，只使用语言内置类型与稳定语法，把随语言演进失效的风险降到最低，并由 CI 在每次提交时以最新工具链三后端验证。当前已交付 17 次有效提交：

- **分配器**：`Allocator` trait + Bump（O(1) 帧式分配）/ Slab（定长块池、双释放检测、LIFO 复用）/ Buddy（2 的幂可变块、伙伴合并、免 size 释放）三种块分配器 + `Arena[T]` 类型化 arena；offset 句柄直接下标读写载荷字节（`storage()`），分配路径零堆分配（句柄为纯 Int 偏移，分配/释放本身不创建任何对象）
- **容器**：RingBuffer（SPSC 友好 FIFO）、FixedDeque（work-stealing 双端队列）、SparseSet（ECS 存活集，增删查 O(1)、遍历 O(len)）、BitVec（`UInt64` 位向量 + popcnt）
- **质量体系**：契约化 API（`Option` = 资源耗尽、`abort` = 契约违反）；每模块确定性伪随机属性测试 + 场景演示测试共 42 个（js/wasm-gc 本机全过，native 由 CI 覆盖）；`moon check` 零警告；CI 三后端矩阵 + 零 FFI 门禁 + native release 基准（2 个基准套件）

## 项目方向与适用场景

**方向**：开源库 / 生态包（底层基础设施）。

- **游戏服务器**：每实体一块（Slab）+ 存活集（SparseSet）+ 帧内临时对象（Arena/Bump）+ 有界事件队列（RingBuffer）+ 任务窃取队列（FixedDeque）。仓库内 `examples/` 以迷你权威服务器端到端演示该组合：200 tick 随机客户端流量，模型镜像逐 tick 校验 8 项不变量
- **嵌入式与实时系统**：确定性内存、无 GC 抖动、零 FFI——未来 MoonBit 支持裸机目标时本库可直接跟上
- **编译器与运行时**：阶段式 arena 管理 AST/中间表示；malloc 风格可变块分配
- **调度与并发基础设施**：work-stealing 任务队列、SPSC 事件通道（结构本身无锁且从不覆写，跨线程内存序在 M3 补齐）

## 测试与验收场景

全部可复现，详见仓库 [docs/acceptance.md](../docs/acceptance.md)（7 项验收清单）：

1. **功能验收**：`moon test --target js / wasm-gc / native` —— 42 个测试全过（每模块确定性伪随机属性测试 + 200-tick 端到端模型镜像）
2. **静态质量**：`moon check` 零警告；CI（push 即触发）在最新工具链上跑 检查 + 三后端测试 + native release 基准 + 零 FFI 门禁
3. **场景验收（一键）**：`moon run src/examples --target js` —— 200-tick 随机流量确定性输出（有界降载丢弃、命令 arena 零溢出）
4. **契约验收**：资源耗尽返回 `Option`（满池/队满），契约违反 `abort`（双释放检测）；对照基准量化与 core GC 容器的成本差

## 项目类型说明

**原创项目**。分配器设计参考经典算法：buddy/slab 为公开教科书算法，bump 的整场 reset 语义借鉴 Zig `std.heap.FixedBufferAllocator` 的 arena 约定——均为设计思路参考，代码全部原创，无移植、无第三方代码引用。

**开源合规**：Apache-2.0（LICENSE 文件已入库，moon.mod 同步声明）；仓库公开可访问：<https://github.com/QYF795/moonbase>；以 MoonBit 为主要实现语言（100%，零 FFI）；README、可运行示例（examples）、CI、测试齐全。
